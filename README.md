## 🌟 Featured Project: Advanced TinyBERT Spam Classifier
This is the highlight of my internship. I transitioned from a basic Naive Bayes approach to a **Transformer-based TinyBERT** model for state-of-the-art accuracy.

- **Live Demo:** [Click here to try the App](https://huggingface.co/spaces/b098/spam-detector-ai)
- **Model Hub:** [View model on Hugging Face](https://huggingface.co/b098/tinybert-spam-classifier)
- **Tech Stack:** PyTorch, Hugging Face Transformers, Streamlit, Pandas.
- **Innovation:** Optimized for speed (TinyBERT is 28x faster than BERT) while maintaining high precision.
